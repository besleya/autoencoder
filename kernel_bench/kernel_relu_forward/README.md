# kernel_relu_forward Replacement Benchmark

This benchmark compares the original grid-based CUDA kernel for ReLU forward pass with a Thrust-based replacement.

## Files

- **original.cu** — Original kernel from `/mnt/home/besleya/autoencoder/layer.cu` (line 73)
- **replacement.cu** — Thrust-based implementation using `thrust::transform` with device lambda
- **reference.py** — Python script to generate test data using PyTorch
- **test_accuracy.cu** — Accuracy test comparing outputs (tolerances: rel=1e-5, abs=1e-6)
- **bench.cu** — Benchmark with 10 warmup + 100 timed iterations
- **Makefile** — Build configuration
- **run_tests.sh** — SLURM submission script

## Original Kernel

```cuda
__global__ void kernel_relu_forward(int size, float* a, const float* z) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < size) {
        a[idx] = fmaxf(z[idx], 0.0f);
    }
}
```

Launched with standard grid/block configuration at `layer.cu:620` in `_apply_activation_forward()`.

## Thrust Replacement

```cuda
void relu_forward_thrust(int size, float* a, const float* z, cudaStream_t stream) {
    thrust::transform(
        thrust::cuda::par.on(stream),
        thrust::device_pointer_cast(z),
        thrust::device_pointer_cast(z) + size,
        thrust::device_pointer_cast(a),
        [] __device__ (float v) { return v > 0.0f ? v : 0.0f; }
    );
}
```

Uses `thrust::device_pointer_cast` to wrap raw device pointers and executes on the specified CUDA stream.

## Testing

### Local (CPU-less compile check)

```bash
/usr/local/cuda/bin/nvcc -c -O3 -std=c++17 --gpu-architecture=sm_90 --extended-lambda -I/usr/local/cuda/include original.cu -o /tmp/orig_krf.o
/usr/local/cuda/bin/nvcc -c -O3 -std=c++17 --gpu-architecture=sm_90 --extended-lambda -I/usr/local/cuda/include replacement.cu -o /tmp/repl_krf.o
/usr/local/cuda/bin/nvcc -O3 -std=c++17 --gpu-architecture=sm_90 --extended-lambda -I/usr/local/cuda/include test_accuracy.cu original.cu replacement.cu -o /tmp/link_krf_test -L/usr/local/cuda/lib64 -lcudart -lcublas -lcusparse -lnvToolsExt -lpthread
/usr/local/cuda/bin/nvcc -O3 -std=c++17 --gpu-architecture=sm_90 --extended-lambda -I/usr/local/cuda/include bench.cu original.cu replacement.cu -o /tmp/link_krf_bench -L/usr/local/cuda/lib64 -lcudart -lcublas -lcusparse -lnvToolsExt -lpthread
```

### With GPU (SLURM)
